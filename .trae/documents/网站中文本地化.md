# 网站中文本地化方案

## 需求分析
将网站的原生文字转换为中文，保留特定的英文名称（如软件名、新闻来源等）

## 需要翻译的文件和内容

### 1. NewsPage.tsx (新闻页面)
- 分类名称翻译：Breaking News → 热门新闻, Video AI → 视频AI, Language Model → 语言模型, Industry → 行业, Image AI → 图像AI, Health → 健康, Multimodal → 多模态, Audio → 音频
- 时间描述：2小时前, 4小时前 等（保留）
- "收起" → "收起"
- "阅读原文"（保留）
- 新闻来源保留英文：OpenAI, TechCrunch, Anthropic, Nature, Stability AI, Meta, Google, Suno 等

### 2. MusicPage.tsx (音乐页面)
- 今日推荐标签（已是中文）
- 风格分类：Synthwave → 合成器波, Ambient → 环境音乐, Electronic → 电子音乐, Chill → 放松音乐
- 音乐人名称保留英文
- 保留播放/暂停按钮文字

### 3. NewsWidget.tsx (首页新闻组件)
- Breaking News → 热门新闻
- 时间描述：2 hours ago → 2小时前
- 新闻来源保留英文：OpenAI

### 4. MusicWidget.tsx (首页音乐组件)
- Daily Track → 每日推荐
- 歌曲名和艺术家保留英文

### 5. TrendingWidget.tsx (首页趋势组件)
- Trending Topics → 热门话题
- 趋势话题保留英文标签：#Sora, #Gemini1.5 等

### 6. NavPage.tsx (导航页面)
- 已是中文：聊天机器人, 图像生成, 视频生成, 音频生成, 编程工具
- 工具名称保留英文：ChatGPT, Claude, Midjourney 等

## 实现计划

1. 翻译 NewsPage.tsx 中的分类和UI文字
2. 翻译 MusicPage.tsx 中的风格分类名称
3. 翻译 NewsWidget.tsx
4. 翻译 MusicWidget.tsx
5. 翻译 TrendingWidget.tsx
