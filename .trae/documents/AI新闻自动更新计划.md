# AI新闻自动更新实现计划

## 问题分析

项目中有**两套**新闻数据系统：

### 1. `server/index.js` - Express后端服务器（端口3001）
- 有 `syncNews()` 函数和自动更新机制
- 当前每 **30分钟** 自动更新一次新闻
- 使用 SQLite 数据库存储新闻数据
- 有 `/api/sync` 接口可以手动触发更新

### 2. `api/index.js` - Vite内置API处理函数
- 这是静态假数据，**没有任何自动更新机制**
- 只在内存中存储数据，服务器重启会重新初始化

### 根本原因
- 当前运行 `npm run dev` 时，只启动了 Vite 开发服务器
- Vite 的 `/api` 代理指向 `server/index.js`（端口3001）
- 但如果后端服务器未运行，代理会失败

---

## 解决方案

### 方案一：使用 npm run start（推荐）

修改启动方式：
```bash
npm run start
```
这会同时启动：
- 后端服务器（端口3001）- 负责新闻自动更新
- Vite开发服务器（端口3000）- 负责前端页面

**后端服务器已有自动更新机制**：每30分钟自动同步新闻

### 方案二：增加每日定时更新功能

在 `server/index.js` 中增加每天固定时间（如早上8点）自动更新：

1. 保留现有的30分钟间隔更新
2. 增加每日定时任务（使用 node-cron 或 setTimeout）
3. 可在 `/api/health` 中返回下次更新时间

### 方案三：前端手动触发更新

在NewsWidget中添加"刷新新闻"按钮，点击调用 `/api/sync` 接口

---

## 具体实施步骤

### 步骤1：修改 package.json 启动脚本
- 确保 `npm run start` 命令正确配置

### 步骤2：在 server/index.js 中增加每日定时更新
- 保留现有的30分钟间隔更新（作为辅助）
- 增加每日固定时间更新（如每天早上8:00）
- 在健康检查接口返回下次更新时间

### 步骤3（可选）：前端添加刷新按钮
- 在新闻组件中添加手动刷新功能
- 显示"最后更新时间"

### 步骤4：验证功能
- 启动应用并确认新闻自动更新正常工作

---

## 预期效果

1. 使用 `npm run start` 启动后，新闻会自动每30分钟更新
2. 每天固定时间（如早上8点）会强制更新一次
3. 可以在界面上看到最后更新时间
4. 可以手动点击刷新按钮立即更新新闻
