# 软件榜美化计划

## 目标
采用极简卡片式布局，分类作为标签放在右上角，去掉星级显示，使软件榜更加简洁美观。

## 设计方案：极简卡片式 + 右上角分类标签

### 卡片结构
```
┌─────────────────────────────────────────┐
│ [排名] [软件名称]          [分类标签]   │
│        [★评分] [🔥热度]                 │
└─────────────────────────────────────────┘
```

**具体元素：**
- **排名**: ①②③金色，④-⑩蓝色，10+灰色（使用圆圈数字）
- **软件名称**: 加粗，白色，16px
- **分类标签**: 右上角，圆角标签，彩色背景
- **评分**: ★4.8（黄色星星图标+数字）
- **热度**: 🔥1.8亿（火焰图标+简化数值）
- **去掉星级可视化**
