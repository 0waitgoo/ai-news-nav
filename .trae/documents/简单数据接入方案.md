# 软件榜真实数据简单接入方案

## 目标
用最简单、最容易实现的方式接入真实的软件排名数据。

## 方案选择：GitHub Actions 自动更新（推荐）

### 为什么选这个方案？
1. **免费** - GitHub Actions 免费额度足够
2. **简单** - 不需要服务器，不需要API密钥
3. **自动化** - 每周自动运行，自动提交更新
4. **可靠** - GitHub托管，稳定可靠

### 步骤2: 创建GitHub Actions工作流
**文件**: `.github/workflows/update-ranking.yml`

```yaml
name: 每周更新软件榜数据

on:
  schedule:
    # 每周一凌晨2点运行
    - cron: '0 2 * * 1'
  workflow_dispatch: # 允许手动触发

jobs:
  update:
    runs-on: ubuntu-latest
    
    steps:
    - name: 检出代码
      uses: actions/checkout@v3
      
    - name: 设置Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
        
    - name: 安装依赖
      run: npm ci
      
    - name: 运行更新脚本
      run: node scripts/update-ranking.js
      
    - name: 提交更新
      run: |
        git config --local user.email "action@github.com"
        git config --local user.name "GitHub Action"
        git add api/index.js
        git diff --quiet && git diff --staged --quiet || git commit -m "自动更新软件榜数据 [$(date +%Y-%m-%d)]"
        git push
```

### 步骤3: 数据来源选择（按实现难度排序）

#### 方案A: 使用公开数据源（最简单）
**数据来源**: 
- a16z Top 100 榜单（每半年更新）
- Product Hunt 每日热门
- GitHub Trending

**实现方式**: 
- 爬虫抓取网页
- 解析HTML获取数据
- 更新到 `api/index.js`

**优点**: 免费，无需API密钥
**缺点**: 数据可能不够实时

#### 方案B: 使用免费API（推荐）
**数据来源**:
- **AlternativeTo API** - 软件评分和排名
- **Product Hunt API** - 每日热门产品（免费额度足够）

**实现方式**:
- 申请免费API密钥
- 调用API获取数据
- 更新到 `api/index.js`

**优点**: 数据结构化，易于处理
**缺点**: 需要申请API密钥

## 推荐实施方案

### 第一阶段：使用Product Hunt API（1-2天完成）

1. **申请Product Hunt API密钥**
   - 访问 https://www.producthunt.com/v2/oauth/applications
   - 创建应用获取Token

2. **创建简单的API调用脚本**
   ```javascript
   // scripts/fetch-producthunt.js
   const fetch = require('node-fetch');
   
   async function getProductHuntData() {
     const response = await fetch('https://api.producthunt.com/v2/api/graphql', {
       method: 'POST',
       headers: {
         'Authorization': 'Bearer ' + process.env.PRODUCT_HUNT_TOKEN,
         'Content-Type': 'application/json',
       },
       body: JSON.stringify({
         query: `
           query {
             posts(first: 20, topic: "artificial-intelligence") {
               edges {
                 node {
                   name
                   tagline
                   votesCount
                   website
                 }
               }
             }
           }
         `
       }),
     });
     
     const data = await response.json();
     return data.data.posts.edges.map(edge => edge.node);
   }
   ```

3. **设置GitHub Secrets**
   - 在GitHub仓库设置中添加 `PRODUCT_HUNT_TOKEN`

4. **完成！** 每周自动更新数据
